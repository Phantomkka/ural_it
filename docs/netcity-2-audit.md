# NETCITY 2.0 — аудит управления и onboarding
Основа — игра открытого PR #10: main содержит только README. Рабочая версия игры не изменялась.

| Проблема | Приоритет | Решение | Проверка |
| --- | --- | --- | --- |
| Непонятное включение WASD | P0 | Явная подсказка и фокус сцены | Движение после клика |
| Нет меню Escape | P0 | Настройки с остановкой ввода | Удержать W и открыть меню |
| Фиксированные клавиши | P0 | Переназначение без конфликтов | Z сохраняется после reload |
| Нет обучения | P0 | Четыре проверяемых шага и повтор | Движение, обзор, осмотр, награда |
| Дискретная камера | P1 | Сглаживание подтверждённой позиции | Прежние сценарии дверей и ремонта |
| Перегруженный телефон | P1 | Компактный HUD и настройки | Мультитач и отсутствие горизонтального скролла |

Путь новичка: вход → обучение → карта → офис → серверная → осмотр → порт №3 → награда → снабжение → следующая работа.
Клики по интерфейсу не захватывают мышь; поля ввода не запускают движение. Space/F не обещают несуществующие действия.
I/J открывают профиль и работы, M — карту, H/? — помощь. Качество, чувствительность, инверсия и громкость сохраняются локально.
