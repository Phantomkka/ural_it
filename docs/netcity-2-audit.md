# NETCITY 2.0 — Controls & Onboarding
Основа — полная игра открытого PR #10; main пока содержит только README.
Рабочая версия не изменялась.

| Проблема | Приоритет | Исправление | Проверка |
| --- | --- | --- | --- |
| Непонятное включение WASD | P0 | Явная подсказка захвата и фокус сцены | Движение после клика |
| Нет меню Escape | P0 | Настройки и остановка ввода | W + Esc останавливает героя |
| Фиксированные клавиши | P0 | Переназначение без конфликтов | Z сохраняется после reload |
| Нет обучения | P0 | Четыре шага и повтор обучения | Движение, обзор, осмотр, первая работа |
| Дискретная камера | P1 | Сглаживание позиции | Прежние сценарии дверей и ремонта |
| Перегруженный телефон | P1 | Компактный HUD и меню | Touch, мультитач, отсутствие горизонтального скролла |

Путь новичка: вход → обучение → карта → офис → серверная → осмотр → порт №3 → награда → снабжение → следующая работа.
Space/F не обещают несуществующие действия. I/J открывают профиль и работы, M — карту, H/? — помощь.
