# NETCITY ONLINE

Первый рабочий прототип браузерной 3D MMO: одна общая улица, до 32 игроков в комнате, вид от первого лица. Бесплатные open-source библиотеки; внешние сервисы и аккаунты для игры не нужны.

## Запуск

Требуется Node.js 22.12+ (проверено с 24) и npm 10+.

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173` в двух вкладках или разных браузерах. Нажмите на улицу для захвата мыши. WASD — движение, мышь — обзор, Esc — освободить курсор. На сервере появятся два игрока; каждый видит второго как бирюзовую капсулу. Закрытие вкладки удаляет игрока. Кнопка «Переподключиться» создаёт новую сессию после разрыва связи.

Для игры с другого компьютера в локальной сети откройте адрес компьютера с Vite на порту 5173. Захват мыши зависит от политики браузера; для удалённого размещения используйте HTTPS. Vite проксирует `/game` (HTTP matchmaking и WebSocket) на сервер `127.0.0.1:2567`. Не выставляйте Vite dev server в публичный интернет.

## Команды

```sh
npm run typecheck
npm test
npm run build
npm run test:browser
npm run start -w @netcity/server
```

Сборка клиента находится в `apps/client/dist`. Для production раздавайте её через HTTP(S) сервер и проксируйте `/game` с поддержкой WebSocket на игровой сервер. Альтернатива — установить `VITE_SERVER_URL=wss://your-game-host` при сборке клиента. Серверный порт задаётся через `PORT` (по умолчанию 2567); при изменении порта также измените целевой адрес proxy в `apps/client/vite.config.ts`. `vite preview` не заменяет production proxy.

## Модули

- `apps/client`: React UI, Vite, Babylon.js; сцена, управление и визуализация реплик состояния.
- `apps/server`: Node.js, Colyseus; создание комнат, жизненный цикл игроков, авторитетная симуляция.
- `packages/shared`: протокол ввода, размеры зданий, ограничение скорости и столкновения.

Сервер обновляет мир 30 раз в секунду. Клиент отправляет только намерение движения, не координаты и не время. Нормализация диагонали ограничивает скорость до 5 единиц/с; частота сообщений не ускоряет игрока. Некорректные числа и ввод вне диапазона отбрасываются. Ввод истекает через 250 мс без сообщений, поэтому потерявший связь клиент не продолжает двигаться. Здания и границы мира проверяются на сервере. Клиент показывает подтверждённое положение своего игрока, остальные позиции визуально сглаживает.

## Проверки

`npm test` проверяет валидацию ввода, скорость диагонального движения, границы, столкновения и настоящий Colyseus-сервер с двумя WebSocket-клиентами: общую комнату, репликацию, поток сообщений, истечение ввода и отключение. Интеграционный тест использует локальный порт 26789.

`npm run test:browser` запускает Chromium через Playwright, проверяет сцену Babylon (10 зданий и второй персонаж), захват мыши, движение WASD, отображение перемещения у второго игрока и удаление его модели после отключения. По умолчанию нужен `/usr/bin/chromium`; другой исполняемый файл задаётся через `CHROMIUM_PATH`. Dev-сервер запускается тестом автоматически.

## Границы прототипа

Одна улица без сохранения мира, аккаунтов, чата, экономики, магазинов и симуляции сетей. Нет предсказания движения, мобильного управления или распределения нагрузки между процессами. Это основа для разработки, не готовая массовая MMO. Комнаты и игроки исчезают при перезапуске сервера.
