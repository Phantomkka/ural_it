# NETCITY 2.0

Многопользовательская браузерная IT-игра про инженеров Новолинска: улица, офис, серверная, оборудование, диагностика рабочих мест, NET/XP, снабжение и личная сервисная бригада. Babylon.js, React/Vite/TypeScript, Colyseus и PostgreSQL. NET — только виртуальные игровые кредиты.

Разработка по [Issue #11](https://github.com/Phantomkka/ural_it/issues/11), отдельными последовательными PR поверх интеграционного PR #10. Merge и обновление рабочей версии выполняются только после отдельного подтверждения.

## Запуск

Node.js 22.12+ и npm 10+:

```sh
npm ci
npm run dev
```

Откройте адрес Vite, показанный в терминале. Для двух независимых игроков используйте разные браузеры или независимые browser context: вкладки одного браузера могут использовать один сохранённый профиль.

## Управление

| Действие | ПК по умолчанию |
| --- | --- |
| Движение / бег | WASD / Shift |
| Обзор | Мышь после явного клика по улице |
| Взаимодействие | E при контекстной подсказке, до 2,5 м |
| Меню / освобождение мыши / закрытие панели | Esc |
| Профиль, инвентарь и работы | I / J |
| Карта / помощь | M / H или ? |

Клавиши переназначаются без конфликтов. Настройки сохраняют чувствительность, инверсию Y, громкость и графику; там же доступен полный экран. Прыжка и фонарика нет — Space/F не обещают несуществующие действия. Поля ввода не запускают движение, интерфейс не захватывает мышь.

На телефоне: стик слева, камера свайпом справа, «Осмотреть» и удержание «Бег». Работают два пальца одновременно. Меню, потеря фокуса и уход вкладки в фон останавливают ввод; мир для других игроков продолжает работать.

## Первая смена и игровой цикл

Обучение проверяет движение, обзор, осмотр и первую награду; можно пропустить и повторить. Диспетчер Алина объясняет маршрут, Марат ведёт к снабжению. Логотип открывает главное меню.

Войдите в офис справа от центра улицы, пройдите через коридор и вторую дверь в серверную. Осмотрите коммутатор и подключите отключённый кабель в порт №3. Карта, направление, расстояние и журнал помогают найти цель.

| Работа | Реальные игровые действия | Награда |
| --- | --- | --- |
| Сетевой порт | Осмотр и правильный порт; повторная работа требует расходник | 100 NET / 60 XP |
| Охлаждение | Взять работу, купить баллон, осмотреть и очистить стойку инструментами | 80 NET / 50 XP |
| Рабочие места | Разные сценарии кабеля, адресации и DNS; диагностика, исправление и повторная проверка | 60 NET / 40 XP за каждый ПК один раз на профиль |

Терминал — игровой симулятор, без обращения к реальным сетям. Награды подтверждаются сервером; повтор закрытия не даёт деньги. На доске одновременно активна одна работа. Инструменты, цены и остатки видны в снабжении.

«Моя IT-бригада» содержит контракт «Офис под ключ»: общая сеть и три ПК дают одну единицу репутации без дополнительной выплаты. Блок свёрнут, чтобы не мешать первой работе. Это одиночный срез компании; приглашения и командные бюджеты ещё не реализованы.

## Профиль

Гостевой доступ запоминается на устройстве и переживает закрытие вкладки. Старая вкладка сохраняет свой профиль и не заменяет другой сохранённый профиль. При недоступном хранилище HUD указывает ограниченный срок доступа. Ошибка авторизации не создаёт нового гостя вместо постоянного профиля.

Очистка данных сайта и приватный режим могут удалить доступ. Полноценные аккаунты, перенос между устройствами и восстановление после очистки пока не реализованы. Настройки хранятся в браузере; профиль, инвентарь и выполненные работы сохраняются с PostgreSQL. Без постоянного хранилища явно показано «Временные данные». Мир и позиции временные.

## Проверки и материалы

```sh
npm run typecheck
npm test
npm run build
npm run test:browser
npm run test:postgres
```

PostgreSQL-проверки используют отдельный тестовый экземпляр с TEST_DATABASE_URL. Для браузера задайте CHROMIUM_PATH; на Windows по умолчанию установленный Edge. Результаты и trace ошибок остаются в test-results.

Проверенная серия: 36 серверных, 12 PostgreSQL-проверок и 20 браузерных сценариев; после компактного отображения компании отдельно повторены три сценария компании и снабжения. Touch — эмуляция Chromium, не физический телефон.
